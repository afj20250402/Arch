1. 基本方針

Archは中央のサーバーを持たないP2P型のSNSであり、投稿・メッセージ等の内容を運営（Arch提供元）が 集約して保持しない設計です。これを踏まえ、本ポリシーは次の考え方に立ちます。

  1. 取得しないことを最優先します。技術的に取得を避けられる情報は、取得しない設計を優先します。
  2. 取得する場合は最小限にします。保存する範囲と期間を必要最小限にとどめます。
  3. 該当する前提で義務を果たします。「個人情報取扱事業者に当たらない」ことを狙うのではなく、 当たる前提で本ポリシーに定める義務を履行します。
  4. 暗号化により内容を関知しません。会員限定ルームや個人間のやり取りは端末どうしで暗号化し、 運営を含む第三者が内容を読めない設計とします。

3. 取得する情報・取得しない情報

Archでは情報が2つに分かれます。端末の中だけに保たれ運営が取得しないものと、 運営が関与しうる経路を通じて運営が取得しうるものです。

3-1. 運営が取得しないもの

  • 投稿の本文・画像・動画・音声、チャットメッセージの内容
  • 会員限定ルームでのやり取りの内容
  • フォロー関係・閲覧履歴などの利用状況

これらは各端末が保持し、暗号化された状態で端末どうしを直接流れます。運営が管理するデータベースには保存しません。

3-2. 運営が取得しうるもの

アカウントの情報 公開鍵にもとづく利用者ID、任意で登録される表示名・アイコン等。 鍵はご利用者の端末上で作られ、運営を含むいかなる第三者にも預けられません。 運営がIDを把握しうるのは、ご利用者が自ら公開し、または接続した場合に限られます。
通信に伴う情報 接続時のIPアドレス・接続日時等。運営は常時稼働するサーバーを持ちませんが、 運営が間欠的に起動するノードと接続した際に、当該ノードがこれらを一時的に取得することがあります。 保持する期間は必要最小限とし、内容を認識できない形での処理を優先します。
端末・利用状況の情報 OSの種別、アプリのバージョン、不具合の記録等。品質改善のため、 ご利用者が送信に同意された場合にのみ取得します。

4. 利用目的

取得した情報は、次の目的の範囲内でのみ利用します。

  1. アカウントの発行と認証
  2. 端末どうしの接続の確立
  3. 不正アクセス・なりすまし・迷惑行為への対応
  4. 品質の維持・改善（同意をいただいた場合に限ります）
  5. お問い合わせへの対応
  6. 法令に基づく対応（開示のご請求、漏えいの報告等）

目的の達成に必要な範囲を超えて個人情報を取り扱いません。目的を変更する場合は、 変更後の目的を本ポリシーの改訂により公表します。

5. 第三者への提供

  • 法令に基づく場合を除き、ご本人の同意なく個人情報を第三者へ提供しません。
  • 稲荷寿司の鍵の管理を担う事業者は、認証のためメールアドレス等をその事業者自身のサービスとして取得・処理します。 これは運営による第三者提供ではなく、ご利用者がその事業者のサービスを直接ご利用になる構造です。 当該事業者のプライバシーポリシーが別途適用されます。 なおアカウントの鍵の管理はこの事業者を介さず端末上で完結するため、この経路での情報の提供は生じません。
  • P2Pという性質上、公開の設定で投稿された情報は、ネットワークに参加する他の端末へ直接流れます。 これは運営による第三者提供ではなく、ご利用者ご自身の公開行為にもとづく流通です。

運営の業務の一部を外部の事業者へ委託する場合は、委託先に対して適切な監督を行います。

6. 安全管理のための措置

  • 会員限定ルーム・個人間のやり取りの端末どうしでの暗号化
  • 中継・一時保存を行うノードでの保存期間の最小化
  • 可能な限り、内容を認識できない形での一時保存
  • 公開鍵暗号にもとづくアクセス制御・なりすまし対策

7. 開示・訂正・利用停止・削除等のご請求

P2Pという構造のため、対応できる範囲が端末ごとに異なります。

  • 投稿・メッセージの削除——削除（撤回）の指示は、投稿されたご本人の鍵によってのみ発行できます。 各端末はこれを尊重して伝えます。運営が他の方の投稿を強制的に削除する機能は設けていません。
  • 運営が保持する情報（3-2）の開示・訂正・利用停止・削除のご請求——法令の定めに従い、 ご本人からのご請求をお受けし、遅滞なく対応します。窓口は2章のメールアドレスです。
  • 運営のノードでの配信停止——運営が間欠的に起動するノードが一時保存・中継している情報について、 権利侵害等のお申し出を受けた場合は、当該ノードからの配信を停止します。 ただし、すでに他の方の端末へ渡った情報に及ぶものではありません。

8. Cookie等について

この公式サイトでは、アクセス解析・広告のためのCookieやトラッカーを設置していません。 外部のフォント・スクリプト・画像の読み込みも行いません。

ご利用者が外部のサービスのウェブ画面をご利用になる場合は、当該サービスのCookie等が用いられることがあり、 その取扱いは当該サービスのプライバシーポリシーに従います。

9. 年齢の条件

年齢の基準は段階的に設けます。国・地域を問わず世界共通の基準とし、いずれの段階でも 法定代理人（保護者）の同意による手続きは設けません。基準の年齢に満たない方はご登録いただけません。

  • 2026年内——ご登録・お支払いのいずれも18歳以上の方のみ。
  • 2027年以降——SNSとしてのご登録の下限を16歳へ引き下げます。 稲荷寿司の購入・消費などの機能は引き続き18歳以上の方のみです。

10. 漏えい等が起きたとき

個人データの漏えい・滅失・毀損等が生じ、法令の定める要件に該当する場合は、 個人情報保護委員会への報告およびご本人への通知を、法令に定められた期限内に行います。

11. 本ポリシーの変更

本ポリシーは、法令の変更等に応じて改訂することがあります。 重要な変更を行う場合は、アプリ内のお知らせまたはこのサイトでの公表によりお知らせします。

12. お問い合わせ窓口
